# SMART BUILD — Ақылды есептеу, тиімді құрылыс.

Үй салу мен ішкі әрлеуге қажетті материалдардың мөлшерін, құнын, жалпы бюджетті және үнемдеу мүмкіндігін математикалық жолмен есептейтін қазақ тіліндегі мобильді веб-қосымша (PWA).

> SMART BUILD — құрылыс шығындарын алдын ала жоспарлауға арналған математикалық құрал. Ол кәсіби инженерлік жобалау, конструкциялық есептеу немесе ресми құрылыс сметасының орнына қолданылмайды.

## Мүмкіндіктер

- 4 үй түрі: шағын үй, отбасылық үй, екі қабатты үй, өз жобам (күрделі пішін — тік төртбұрышты бөліктер, қабаттасу бір рет есептеледі; немесе аудан/периметр қолмен).
- 15 материал: кірпіш (екі түрі: қызыл кірпіш — цемент-құм ерітіндісімен, газоблок — арнайы желіммен, данамен немесе м³-пен), бетон, цемент, құм, шатыр жабыны, жылу оқшаулағыш (атауы өзгертіледі), тұсқағаз, линолеум, галтель, плинтус, бояу, желім, сылақ қоспасы, еден тегістейтін қоспа, кафель (плитка — ауданы, өлшемі мен жігі бойынша: дана / м² / қорап). Әрқайсысында автоматты/қолмен режим, қор коэффициенті, бірлік бағасы.
- Бөлмелер бойынша әрлеу (тұсқағаз мен бояу бір қабырғаға тек арнайы таңдағанда қатар есептеледі).
- Дайын бетон / өзім дайындаймын — екі сценарий, шығын екі рет есептелмейді.
- Жеткізушілерді салыстыру: жеткізу құны, ең аз тапсырыс, «бір жеткізуші» және «бірнеше жеткізуші» (барлық үйлесімдер толық тексеріледі).
- Бюджет: D = B − C, үш сценарий (үнемді / стандарт / жоғары) — тек енгізілген бағалармен.
- Формулалар пайдаланушыға көрсетілмейді: экранда және PDF/Excel-де тек дайын нәтижелер (аудан, мөлшер, құн, бюджет, үнем). Есептеу алгоритмдері `src/lib/math.ts` пен `src/lib/engine.ts`-те өзгеріссіз сақталған және тесттермен тексеріледі.
- Құрылыс терминдері толық атаумен: «Таспалы іргетас», «Плиталық іргетас», «Төбе галтелі», «Еден плинтусы», «Теплород жылу оқшаулағыш материалы», «Қабырға сылағы», «Еденді тегістейтін қоспа»; әр материалдың жанындағы (i) белгісі қысқа түсіндірме ашады.
- Нұсқаларды салыстыру (ғылыми зерттеу): мөлшер өзгерісі, құн айырмасы, үнем сомасы мен пайызы, бюджетке сәйкестік; зерттеу нәтижесін PDF/Excel-ге экспорттау.
- Сақтау: IndexedDB (автоматты), JSON экспорт/импорт. Экспорт: PDF (DejaVu Sans — қазақ әріптері мен ₸), Excel, басып шығару.
- Офлайн жұмыс (Service Worker), телефонға орнату. Сервер, API кілті, тіркелу қажет емес.

### Жылдам есеп (жеке жөндеу жұмыстары)

Үй жобасынсыз бір бөлмеге: «Тұсқағазды ауыстыру», «Линолеумды ауыстыру», «Қабырғаны бояу», «Төбені жаңарту», «Қабырғаны сылау», «Еденді тегістеу» немесе жеке материал (9 әрлеу материалы). Бөлме өлшемі немесе ауданы/ұзындығы қолмен; бағасы, қоры, қаптамадағы өлшемдер; «Менің материалдарымнан» өнім таңдау. Нәтиже: мөлшер, құн, жалпы сома (+ еңбекақы). Бірнеше есеп IndexedDB-де сақталады, PDF / Excel / басып шығару бар. Есептеу негізгі жобадағы функциялармен бірдей (`src/lib/quick.ts`).

### Интерактивті визуализация («Есептеу» бөлімі → Үй макеті / Бөлме / Каталог)

- **Үй макеті:** параметрлік 3D модель (Three.js) — қабат өлшемдері, биіктігі, қабырға қалыңдығы, іргетас, қабат аралық жабын, шатыр еңісі мен свесі жобадан алынады. Айналдыру, екі саусақпен үлкейту, «Бастапқы көрініс». 2D жоспар (нақты контур мен өлшемдер; бөлмелердің орны шартты деп белгіленген) және қасбет (биіктіктер, іргетас тереңдігі, α). Бөлікті басқанда — оның ауданы, сол бөлікке қолданылатын материалдар, мөлшері, бағасы, «Есептеу жолын көру».
- **Каталог:** 14 материалдың иллюстрациясы, қолданылатын орны, бірлігі, «Үлгісін көру» (жобаның нақты параметрлері жазылған қима сызба) және «Есептеуге қосу».
- **Бөлме макеті:** 4 қабырға, еден, төбе, галтель, плинтус; 3D немесе жеңіл 2D; бояу түстері, тұсқағаз бен линолеум текстуралары, «Бұрын / Кейін». Таңдалған бөлменің өз есебі (мөлшер, құн, формулалар).
- **Менің материалдарым:** галереядан/камерадан сурет, атауы, санаты, бірлігі, бағасы, шығын нормасы, орны; текстураны қию, масштабтау, қайталау. Құрылыс қоспаларының суреті текстураға айналдырылмайды. 14 санаттың біріне жатса — сол материалдың формуласымен, «Басқа» болса — `Q = ⌈S × q × (1 + k)⌉` бойынша есептеледі. Жеке материалдар IndexedDB-де сақталып, жобамен бірге JSON-ға экспортталады.
- Түс пен текстура таңдау есепке әсер етпейді; тек әрлеу түрін ауыстыру (мысалы, тұсқағаз → бояу) тиісті материал есебін өзгертеді. 3D модельде тек нақты модельденетін параметрлер өзгереді; пішіні қолмен (аудан/периметр) берілген қабат 3D-де салынбайды — бұл туралы ескерту шығады.

## Материал суреттері

14 материалдың әрқайсысына жеке сурет `src/assets/materials/*.jpg` (800×600, 9–90 КБ) — олар жобаның ішінде, интернетсіз ашылады және Service Worker кэшіне кіреді.

Суреттер физикалық негізделген 3D-рендер (Three.js: PBR материалдар, жұмсақ көлеңке, студиялық жарық) арқылы осы жобаның өзінде жасалған; барлық текстуралар бағдарламалық түрде салынған, бөгде фотосурет қолданылмаған — сондықтан авторлық құқық мәселесі жоқ. Қайта жасау:

```bash
pip install playwright pillow && python -m playwright install chromium
python3 scripts/render-materials/render.py
```

Нақты фотосуретпен ауыстыру үшін сол атаумен (`brick.jpg`, `cement.jpg` …) 4:3 пропорциялы файлды `src/assets/materials/` ішіне салып, `npm run build` жасаңыз. Лицензиясы рұқсат беретін фото ғана қолданыңыз (мысалы, CC0 немесе өзіңіз түсірген).

## Құрылымы

```
src/
  lib/math.ts        — барлық формулалар (таза функциялар + есептеу қадамдары)
  lib/materials.ts   — 14 материалдың сипаттамасы мен параметрлері
  lib/engine.ts      — жобаны толық есептеу (үй, бөлмелер, материалдар, шығын, бюджет)
  lib/compare.ts     — жеткізушілер, сценарийлер, нұсқаларды салыстыру
  lib/report.ts      — PDF/Excel/басып шығаруға ортақ есеп
  lib/exporters.ts   — PDF (pdfmake) және Excel (SheetJS)
  lib/db.ts          — IndexedDB, JSON
  lib/engine.test.ts — автоматтандырылған тесттер (vitest)
  pages/             — Басты бет, Жобаларым, Есептеу (5 кезең), Нәтижелер, Баптаулар
```

Ақша тиынмен (бүтін сан) есептеледі — қалқымалы үтір қатесі жиналмайды. Қап, рулон, дана жоғары дөңгелектенеді (`ceilSafe` 10,0000000001 → 10 қатесінен қорғалған).

## Жергілікті іске қосу

Node.js 18+ қажет.

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # математикалық тесттер
npm run build      # өндірістік build → dist/
npm run preview    # build-ті тексеру (Service Worker тек осында жұмыс істейді)
```

git commit -m "SMART BUILD 1.0"
git branch -M main

## Vercel-ге жариялау

1. https://vercel.com → **Add New → Project** → GitHub репозиторийін таңдаңыз.
2. Framework Preset: **Vite**.
3. Build Command: `npm run build` · Output Directory: `dist` (бұлар `vercel.json`-да да көрсетілген).
4. **Deploy**. SPA маршруттары мен `sw.js`, `manifest.webmanifest` файлдарының баптаулары `vercel.json`-да дайын.

## Телефонға орнату

**Android (Chrome):** сайтты ашыңыз → ⋮ мәзірі → «Қосымшаны орнату» / «Басты экранға қосу».

**iPhone (Safari):** сайтты ашыңыз → «Бөлісу» батырмасы → «Басты экранға қосу» → «Қосу».

Бұл APK емес, PWA (телефонға орнатылатын веб-қосымша). Орнату мен офлайн жұмыс браузер мен ОЖ қолдауына байланысты.

## Не тексерілді

- 52 автоматтандырылған тест (жылдам есеп, газоблок, кафельді қоса) (визуализация–есеп байланысы мен термин атауларын қоса): дөңгелектеу, ақша, бірліктер, 4 үй түріндегі 14 материал, қосарланған шығынның болмауы, жеткізушілер, сценарийлер, бюджет, нұсқалар.
- Headless Chromium-да телефон өлшемінде (390×844) толық сценарий: үй түрін таңдау → параметрлер → бөлмелер → бағалар → жеткізушілер → бюджет → нәтиже → PDF және Excel жүктеу → қайта ашқанда жоба сақталуы → интернетсіз қайта ашу және есептеу. Консольде қате жоқ.
- Визуализация (SwiftShader WebGL арқылы headless режимде): 3D үй және бөлікті басу, 2D жоспар, қасбет, 3D/2D бөлме, бояу мен текстура таңдау, бұрын/кейін, каталог үлгісі, өз суретін жүктеп текстура жасау, оны есептеуге қосу және қабырғаға қолдану.
- PDF пен Excel файлдары ашылып, қазақ әріптері мен ₸ белгісі тексерілді.

**Тексерілмеген:** нақты Android/iPhone құрылғысына орнату, телефондағы 3D жылдамдығы, камерадан тікелей түсіру және iOS Safari-дегі жүктеу әрекеті — бұл ортада физикалық құрылғы жоқ. Жариялағаннан кейін телефонда бір рет тексеріп шығыңыз.

## Лицензия ескертпесі

## Шығын құрамы

Жалпы шығын = құрылыс материалдары + әрлеу материалдары + жеткізу. Жұмысшылардың еңбекақысы есепке кірмейді (оны тапсырыс беруші жұмысшылармен өзі есептеседі).
